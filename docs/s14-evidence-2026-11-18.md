## 5. Gaps & Capture Proposal (Design Only, No Build)

To support all four §14 slots (`cutoff offset`, `spread`, `price impact at fixed notional`, `close-window volume`) without estimation or backfilling, future capture jobs would need to store:

| Source | Missing Fields Needed | Target Capture Window Relative to Start | API / Terms Notes |
| :--- | :--- | :--- | :--- |
| **Polymarket CLOB** | `over_bid_price`, `under_bid_price`, top-5 `bids`/`asks` (`price`, `size_usd`), market `volume_window_usd` (e.g. T-60m to close), `quoted_at` | `T-60m`, `T-30m`, `T-15m`, `T-5m` | Public CLOB `/book` returns full `bids`/`asks` depth ladders; trade/volume requires CLOB trades/Gamma volume delta. |
| **Kalshi** | `yes_bid`, `yes_ask`, orderbook depth levels (`price_cents`, `contracts`), `volume` / `open_interest`, `quoted_at` | `T-60m`, `T-30m`, `T-15m`, `T-5m` | Public `/markets/{ticker}/orderbook` exposes full bid/ask ladder and `volume`; requires capturing `/orderbook` alongside `/markets` in `fetch_kalshi_nba.py`. |
